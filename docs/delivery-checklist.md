# 納品前チェックリスト

実際の状況を付記しています。「検証済み」は実際にスプレッドシート上で動作確認を行った項目、
「【未検証】」は、実際のWordPressサイトへの投稿など、このプロジェクトの中で実際に試せていない・確認できていない項目です。

| # | チェック項目 | 状況 |
| --- | --- | --- |
| 1 | コードがGitリポジトリで管理されている(コミット履歴が残っている) | 完了。ただし、リモートリポジトリへのpushはまだ行っていない |
| 2 | APIキー・パスワード・個人情報などの実値がコード・ドキュメント・コミット履歴に含まれていない | 完了。コード・ドキュメントの変更ごとに秘密情報の検索を実施し、秘密情報を含まないことを確認済み |
| 3 | スクリプトプロパティ(`ANTHROPIC_API_KEY`/`WP_URL`/`WP_USER`/`WP_APP_PASSWORD`/`DRY_RUN`)の設定有無を、値を表示せずに確認できる(「設定を確認」メニュー) | 検証済み。実際にスプレッドシート上でメニューを実行し、5項目の○×表示(値は非表示)を確認した |

## 補足

- 上記の【未検証】項目は、実際のWordPressサイトを用意した上で、まず試運転(DRY_RUN)→本番投稿の順に動作確認を行うことを推奨します。
- 本番投稿を初めて行う際は、必ず1記事だけで試し、WordPress管理画面の「下書き一覧」に正しく表示されることを確認してください。
