# トラブルシューティング

症状ごとに、考えられる原因と対処方法をまとめています。

## よくある症状

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 実行時に「このアプリは確認されていません」「外部サービスへの接続」などの権限エラーが出る | スクリプトの許可(外部サービスへの接続を含む)がまだ済んでいない、または許可が取り消された | メニュー「記事生成」のいずれかの項目をもう一度実行し、表示される許可画面で「許可」を選び直す |
| スプレッドシートを開いてもメニュー「記事生成」が表示されない | ページの読み込みタイミングでメニューがまだ追加されていない | ページを再読み込み(リロード)する。数秒待ってから再読み込みしても出ない場合は、`拡張機能→Apps Script`でコードが保存されているか確認する |
| 「エラー: シート「記事」が見つかりません。」と表示される | シート名が「記事」になっていない(リネームされた、別シートを操作している等) | シート名を「記事」に戻す、または正しいシートに切り替えてから再実行する |
| 記事生成が途中で切れ、エラー欄に「JSONを取得できませんでした」「出力が上限(max_tokens)で途切れた」と出る | 生成する本文が長くなりすぎて、Claude APIの出力上限(max_tokens)に達した | いったんC列を「未生成」に戻して再実行する。繰り返し発生する場合は、キーワードやサブキーワードの数・サンプル記事の長さを見直す(開発者に相談する) |
| 実行中に約60秒前後で通信エラーになる | GAS(UrlFetchApp)の通信には時間の上限があり、Claude APIの応答が時間内に返らなかった可能性がある。**注:この約60秒という値はGoogleの公式ドキュメントに明記された数値ではなく、実運用上の目安です** | いったん再実行する。繰り返し発生する場合は、本文の文字数目安を短くするなど、1回あたりの生成量を見直す |
| 記事生成を連続で何件も実行したら、途中で動かなくなった/タイムアウトした | GASの1回の実行には最長6分という上限があり(Google公式)、これを超えると処理が強制終了される | このツールは1回の操作で1行のみ処理する仕様になっている(複数行の一括処理はできない)。1行ずつ、実行→完了確認→次の行、という進め方をする |
| 記事生成でエラー欄に「Claude APIの呼び出しに失敗しました(HTTP 401)」などHTTPステータス付きのエラーが出る | Claude API側のエラー。HTTPステータスの一般的な意味は下記「Claude APIのHTTPステータス別の対処」を参照 | 下記の表を参照して対処する |
| WordPress下書き保存でエラー欄に「HTTP 401」と出る | WordPressへの認証に失敗している(ユーザー名・アプリケーションパスワードの誤り、アプリケーションパスワード機能が無効など) | `WP_USER`・`WP_APP_PASSWORD` を再発行・再設定する。WordPress側で「アプリケーションパスワード」機能が有効か確認する |
| WordPress下書き保存でエラー欄に「HTTP 403」「code: rest_cannot_create」などが出る | 指定したWordPressユーザーに投稿作成権限がない | ユーザーの権限(役割)が「投稿者」以上になっているか確認する |
| WordPress下書き保存でエラー欄に「HTTP 404」が出る | WordPressのREST APIが無効になっている、パーマリンク設定が原因でAPIのURLが見つからない、または `WP_URL` が間違っている | WordPress管理画面の「設定→パーマリンク」を一度保存し直す。`WP_URL` が正しいサイトのURL(`https://`から始まる)になっているか確認する |
| WordPress下書き保存で「設定エラー: スクリプトプロパティ WP_URL が設定されていません。」などが出る | 必要なスクリプトプロパティ(`WP_URL`/`WP_USER`/`WP_APP_PASSWORD`)が未設定、または `WP_URL` が `https://` で始まっていない | メニュー「設定を確認」で○×を確認し、不足しているプロパティを設定する |

## Claude APIのHTTPステータス別の対処(目安)

このツールのエラーメッセージには、Claude APIから返ってきたHTTPステータスのみが表示されます(詳細な本文は表示されません)。一般的な意味の目安は以下の通りです。**この表の対応関係は一般的なWeb APIの慣習に基づく目安であり、このプロジェクトで実際に全パターンを発生させて確認したものではありません【未検証】。**

| HTTPステータス | 一般的な意味 | 対処の目安 |
| --- | --- | --- |
| 401 | APIキーが無効・間違っている | `ANTHROPIC_API_KEY` を再確認・再発行する |
| 403 | APIキーに権限がない、利用停止など | Anthropicコンソールでアカウント・キーの状態を確認する |
| 429 | レート制限(短時間のリクエスト数が多すぎる) | 少し時間を空けてから再実行する |
| 529 | Claude API側が混雑している(過負荷) | 時間を空けてから再実行する |
| 500番台(その他) | Claude API側の一時的な問題 | 時間を空けてから再実行する。繰り返す場合はAnthropicの稼働状況を確認する |

残高不足(クレジット切れ)の場合も401または403系のエラーとして返ってくることがあります。Anthropicコンソールの請求・使用量ページを確認してください。

## サポートへ連絡するときに伝えてほしい情報

エラーが発生した行については、エラー欄(I列)に原因となったメッセージが残ります(最大200字)。サポートに連絡する際は、次の情報を伝えてください。

- 発生したメニュー操作(「記事生成」か「WordPressに下書き保存」か)
- ステータス(C列)の表示内容
- エラー欄(I列)に表示されている文言(HTTPステータス・`code`の値を含む全文)
- 発生した行のキーワード(A列)

**絶対に伝えないでください:** `ANTHROPIC_API_KEY`・`WP_APP_PASSWORD` の値そのもの。これらはサポート対応に必要ありません。
