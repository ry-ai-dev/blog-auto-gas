- 何をしたか

  - `.gitignore` を作成し、`.env*` / `.clasprc.json` / `.clasp.json` / `node_modules` / `*.key` を除外対象にした
  - `README.md` に目的とフォルダ構成のみを記載(手順は未記載)
  - `src/Code.gs` に以下のスタブを実装
    - シート「記事」の列定義(A:キーワード 〜 I:エラー内容)の定数
    - ステータス値(未生成 / 生成中 / 生成済み / 投稿済み / エラー)の定数
    - `onOpen()`: メニュー「記事生成」とサブメニュー2件を追加
    - `generateForSelectedRow()`: 選択行の検証とステータスを「生成中」→「未生成」に戻すだけのスタブ(Claude API 呼び出しは未実装)
    - `checkSettings()`: スクリプトプロパティの存在確認ダイアログ(値は非表示)
    - `updateStatus()` ヘルパー
  - 権限を現在のスプレッドシートのみに限定するため、@OnlyCurrentDoc を指定した
  - `test/keywords.csv` にサンプル5行を作成(スプレッドシート「ファイル → インポート」で取り込み可能な形式)

  - 次回: Google スプレッドシートを新規作成し、拡張機能 → Apps Script を開いて `src/Code.gs` の内容を貼り付ける予定

### 追記: GAS エディタ・スプレッドシートでの動作確認

- 所要時間: 約25分(確認作業を含む)
- 落とし穴: シート名が「記事」でないと「記事シートが見つかりません」というエラーになる(今回ハマった点)
- 初回の許可画面: 権限の文言は「このアプリケーションがインストールされているスプレッドシートの表示と管理」
  (@OnlyCurrentDoc の効果で、現在のスプレッドシートのみに限定されている)
- スクリプトプロパティの場所: Apps Script エディタの左メニューの歯車アイコン(プロジェクトの設定)→
  下部の「スクリプト プロパティ」から設定する
- `DRY_RUN=true` を追加し、メニュー「記事生成」→「設定を確認」を実行 → ○ になることを確認済み
- 動作確認済みの項目
  - 通常の実行(ステータスが 生成中 → 未生成 に戻る)
  - 見出し行(1行目)を選択して実行 → 何も起きない(想定通り)
  - C列が「生成中」の行で再実行 → 実行されない(重複防止が機能している)
- 気づき: Cursor 側で親フォルダの `.mcp.json`(Supabase 用)が検出されたという確認が出た。
  今回の案件では使用しないため、Claude Code の `/mcp` で無効化した
